Política de Privacidade — Caixa Preta (painel do canal)

Última atualização: 28 de outubro de 2026

O "Caixa Preta" é um painel de uso pessoal do dono do canal Caixa Preta (youtube.com/@caixapreta-tech). Ele roda só no computador do dono do canal e serve para publicar e organizar os vídeos do próprio canal. Não é oferecido a outras pessoas.

Quais dados o app acessa

Com a autorização da conta Google do canal, o app usa as APIs de Serviços do YouTube para:

  • ler o nome e o endereço do canal;
  • enviar vídeos ao canal, com título, descrição, tags, data de publicação, thumbnail e legendas;
  • listar as playlists do canal e colocar vídeos nelas;
  • ler as estatísticas dos vídeos do canal (YouTube Analytics, só leitura).

Com a autorização das contas do próprio canal, o app também usa:

  • a API do Instagram, para publicar os vídeos curtos e os carrosséis do canal;
  • a API de publicação do TikTok, para mandar os vídeos curtos do canal como rascunho para a conta do canal (o dono publica no app do TikTok);
  • o Google Drive do dono do canal, só para guardar por alguns minutos o arquivo que o Instagram precisa baixar; o arquivo é apagado logo depois.

Onde os dados ficam

  • A autorização (o token de acesso) fica guardada só no computador do dono do canal, numa pasta do usuário. Não há servidor do app na internet.
  • Os vídeos e os textos são enviados diretamente do computador para o YouTube, o Instagram e o TikTok.
  • Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como retirar o acesso

A autorização pode ser retirada a qualquer momento em myaccount.google.com/permissions, ou pelo botão "desconectar" do próprio painel. Ao retirar, o token guardado no computador deixa de funcionar.

YouTube e Google

Ao usar o app, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Privacy Policy — Caixa Preta (channel dashboard)

Last updated: October 28, 2026

"Caixa Preta" is a personal dashboard used only by the owner of the Caixa Preta channel (youtube.com/@caixapreta-tech). It runs only on the channel owner's computer, to publish and organize the channel's own videos. It is not offered to anyone else.

Data accessed: with the authorization of the channel's Google account, the app uses YouTube API Services to read the channel name and address; upload videos with title, description, tags, publish date, thumbnail and captions; list the channel's playlists and add videos to them; and read the channel's video statistics (YouTube Analytics, read only). It also uses the Instagram API to publish the channel's short videos and carousels, the TikTok Content Posting API to send the channel's short videos as drafts to the channel's own TikTok account, and the channel owner's Google Drive only to hold, for a few minutes, the file that Instagram downloads (it is deleted right after).

Storage: the authorization token is stored only on the channel owner's computer. There is no app server on the internet. No data is sold, shared with third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: at any time at myaccount.google.com/permissions.

YouTube and Google: by using the app you agree to the YouTube Terms of Service; see also the Google Privacy Policy.
